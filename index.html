NewAPI Backup

NewAPI Backup is a privately operated utility for securely backing up New API database files to Google Drive.

How It Works

The application creates database backups, encrypts them locally using AES-256-GCM, and uploads the encrypted files to the account owner's Google Drive.

Google Drive Access

NewAPI Backup requests the Google Drive drive.file permission to create and manage backup files used by the application.

The application is for authorized administrative use and does not provide public Google account sign-in.
