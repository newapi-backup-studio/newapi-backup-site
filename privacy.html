Privacy Policy

Last updated: November 19, 2026

1. Overview

NewAPI Backup is a privately operated utility used to back up and restore database files through Google Drive.

2. Google Drive Access

The application requests the Google Drive drive.file OAuth permission to create and manage files used by this backup application. It does not request unrestricted access to all Google Drive files.

3. Data Processing

Database backups are encrypted locally using AES-256-GCM before being uploaded to Google Drive. The application stores encrypted backup files in the authorized Google Drive account.

4. Data Retention

Local encrypted backups are normally retained for approximately 30 days. Google Drive backup files are retained until removed by the account owner or an applicable backup retention process.

5. Data Sharing

The application does not sell Google user data. Backup files are not intentionally shared with advertisers. Google Drive stores the encrypted files as part of the backup service.

6. Security

Encryption keys are stored locally using the macOS Keychain. Google OAuth credentials are used to authorize access to backup files.

7. Access and Deletion

The account owner can revoke Google Drive access through Google Account settings and delete backup files from Google Drive. Revoking access does not automatically delete previously uploaded files.

8. Contact

For privacy questions, contact oksweet1103@gmail.com .
